# Release checklist

- [ ] Resolve all findings in the module portability audit.
- [ ] Record the exact R session information.
- [ ] Confirm primary-data redistribution permissions.
- [ ] Select code and derived-data licenses.
- [ ] Complete authors, affiliations and ORCID identifiers.
- [ ] Replace all accession and repository placeholders.
- [ ] Pass module integrity tests in a clean clone.
- [ ] Review figures, Methods and figure legends against frozen outputs.
- [ ] Create a signed or annotated v1.0.0 tag.
- [ ] Attach the frozen bundle and checksums to the GitHub Release.
- [ ] Archive the public release and record the DOI.
