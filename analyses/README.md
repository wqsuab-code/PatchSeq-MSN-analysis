# Analysis modules

- `macaque_morphology/`: frozen macaque M1-M4 morphology and M-T analysis.
- `macaque_ephys/`: reserved for the audited macaque E-class module.
- `mouse_ephys/`: reserved for the audited mouse E-class module.
- `mouse_morphology/`: reserved for the audited mouse M-class module.
- `cross_modal/`: reserved for shared or cross-dataset analyses.
