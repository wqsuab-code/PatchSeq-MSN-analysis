# Source manifest

`source_manifest.csv` records the byte size and SHA-256 of every frozen input
distributed in this module. The mouse measurements were generated in the
present study; a permanent public accession had not been assigned at freeze
time and is therefore marked `PENDING_DEPOSITION` rather than inferred.

Original ASC reconstructions are not present. The ASC entries here are mapping
tables only; exact expected filenames and acquisition status are in
`audit/RAW_ASC_acquisition_status_for_final187.csv`.
