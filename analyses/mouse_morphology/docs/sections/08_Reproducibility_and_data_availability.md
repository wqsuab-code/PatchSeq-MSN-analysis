# Reproducibility and data availability

The frozen analysis is defined by the 187-cell raw ten-feature table, the preprocessing rule, PC1-PC3, Euclidean Ward.D2 hierarchical clustering at K=4, and Seurat graph clustering at resolution 0.50. The repository includes the source tables, assignments, PCA outputs, graph-clustering scan, bootstrap matrices, review-sized 500-repeat machine-learning run tables and split logs, strict T-M RRR inputs and outputs, scripts, interactive web assets, user-saved layouts, figure source files, a SHA-256 manifest and a conflict audit. Two complete high-volume 500-repeat run tables and the 600-dpi TIFF exports are listed by filename, byte size and SHA-256 in the release-assets manifest and are staged outside ordinary Git history.

Three sample-size scopes must remain distinct: n=187 for the complete morphology taxonomy, n=181 for HC-GC morphology consensus, and n=168 for strict D1/D2 plus HC-GC consensus T-M RRR. The actual ASC reconstructions reside on an external drive and are not embedded in this archive; the archive supplies the frozen cell-to-file mapping, availability list and NeuroM recomputation audit so that the original reconstructions can be inserted without changing analytical identifiers.

The Mouse-M analysis was performed using Python 3.14.3, NumPy 2.4.6, pandas 2.3.3, SciPy 1.17.1, scikit-learn 1.8.0 and Matplotlib 3.10.9. A clean rerun of the strict n=168 T-M RRR from the frozen input tables reproduced the archived cell order exactly and reproduced all transcriptomic scores, morphological scores and correlation loadings with a maximum absolute numerical difference below 1.8 × 10−13. Complete package versions and numerical comparisons are retained in the runtime-verification record supplied with the archive.

The mouse Patch-seq measurements and morphology reconstructions were generated in the present study and currently have no public repository accession. A permanent accession and repository URL should therefore be added to the Data Availability statement after deposition; Macaque HMBA, NeMO and DANDI identifiers do not apply to this mouse dataset.
