# Module-separation audit

The mouse E taxonomy uses only mouse electrophysiological predictors with the
`E_` prefix. The frozen feature-order test rejects morphology-prefixed or
morphology-named predictors. Macaque and mouse-morphology modules were consulted
only for repository organization and figure style.

The string `macaqueM_style` survives in one historical grouped-ML provenance
reference because the plotting/validation layout was originally modeled after a
separate analysis. The archived mouse grouped-ML tables contain 450 mouse
consensus cells, mouse E1-E5 labels, recording-date groups and mouse sequencing
batches; they do not contain macaque observations or morphology features.
