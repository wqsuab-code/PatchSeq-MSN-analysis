# Figure legend

**Fig. X | Unsupervised electrophysiological taxonomy defines five consensus E-types in mouse nucleus accumbens medium spiny neurons.** **a,** Fixed t-SNE representation of the 493-cell active cohort, colored by five graph-clustering classes obtained from the first three principal components (PCs) of 18 frozen electrophysiological features. t-SNE was used only for display. **b,** Circular Ward.D2 hierarchical tree generated from Euclidean distances in the same three-PC space; the inner ring denotes hierarchical classes and the outer ring denotes aligned graph-clustering classes. **c,** Cell-count matrix comparing aligned graph-clustering and hierarchical-clustering assignments. Agreement identified 450 of 493 cells (91.28%). **d,** Nested out-of-fold probability matrix for a class-weighted linear support-vector machine trained on the 18 frozen features. Rows denote GC-HC consensus classes and columns denote predicted classes; each cell received one outer-fold prediction. Overall accuracy was 92.0%. **e,** Fixed t-SNE coordinates for the 450 GC-HC consensus cells, colored by E-type (E1, blue; E2, orange; E3, green; E4, cyan; E5, purple). Class sizes were 142, 160, 45, 61 and 42 cells, respectively. **f,** Heat map of feature-wise Z-scores for the 18 frozen electrophysiological features. Cells are grouped by consensus E-type and randomized within class; display values were truncated to the indicated color range without altering stored values. **g,** Representative current-clamp recordings showing two cells per E-type at the indicated current steps. Traces are descriptive examples and were not used to fit the GC-HC taxonomy. **h,** Radar plots of six selected standardized electrophysiological features. Thin pale lines represent individual cells, shaded regions denote the feature-wise interquartile range and dark contours denote the feature-wise median. Cohort-wide Z-scores were linearly mapped to a common radial scale from -3 at the center to +3 at the outer edge and clipped at those limits for display only. All E-types use the same feature order and radial scale. **i,** Percentage composition of strict D1, strict D2 and transcriptomically ambiguous cells within each consensus E-type. **j,** Fixed t-SNE views of the 441 strict transcriptomic-identity cells separated into D1 (n = 209) and D2 (n = 232) populations and colored by consensus E-type; all other active-cohort cells are shown as background where applicable. **k,** Rank-3 transcriptome-to-electrophysiology reduced-rank regression in the 441 strict cells. The upper and lower rows show component 1 versus component 2 and component 1 versus component 3, respectively. The transcriptomic model used 1,000 variable nontechnical genes summarized by 20 transcriptomic PCs; the response matrix comprised the same 18 electrophysiological features. Cell colors denote strict D1 (magenta) and D2 (turquoise) identity. Arrows denote correlations of labeled genes or E-features with the displayed component scores. Ellipses are descriptive 90% bivariate-normal regions calculated separately for D1 and D2 in each component plane; they are neither confidence intervals nor classification boundaries. The in-sample multivariate R² was 0.2958 and is not a cross-validated predictive-performance estimate.

Raw observations are individual cells. No expert-assigned E-type labels were used to define the taxonomy. The primary numerical transformation was minimum shift, feature column-sum normalization to 10,000, `log1p` transformation and feature-wise Z-scoring.
