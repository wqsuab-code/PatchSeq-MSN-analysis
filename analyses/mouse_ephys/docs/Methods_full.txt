Mouse E Type Final Analysis Methods
This document defines the final computational analysis used for the five mouse nucleus accumbens electrophysiological types. The frozen input data were reanalyzed on 24 September 2026 in a recorded R and Python environment, and all prespecified concordance checks passed.

Mouse electrophysiology cohort and preprocessing
Electrophysiological measurements were assembled for 549 recorded cells. Fifty-five cells that failed the predefined electrophysiological quality-control or completeness criteria were excluded, leaving 494 cells with complete measurements for 25 candidate features. The project-wide frozen exclusion list was then applied, yielding the active cohort of 493 cells used for the frozen E-type taxonomy. Expert-assigned electrophysiological labels were not used to fit or define the current taxonomy.
The primary feature panel comprised 18 predefined electrophysiological measurements: holding membrane potential, input resistance, membrane time constant, rheobase, sag ratio, sag time, action-potential threshold, action-potential amplitude, action-potential width, upstroke-to-downstroke ratio, afterhyperpolarization, maximum number of action potentials, latency, latency at +20 pA, interspike-interval adaptation, interspike-interval coefficient of variation, action-potential amplitude adaptation and action-potential coefficient of variation. For each feature, the cohort minimum was subtracted, shifted values were divided by their column sum and multiplied by 10,000, and the resulting values were log1p transformed and standardized to unit variance. A separately evaluated Yeo-Johnson transformation was retained only as a sensitivity branch and was not used for the frozen primary taxonomy.
Principal-component analysis was performed on the standardized 18-feature matrix, and the first three components were used for both clustering procedures. Hierarchical clustering used Euclidean distances and Ward.D2 linkage and was cut at K=5. Graph clustering used a shared-nearest-neighbor graph (k=20; pruning threshold 1/15), Louvain optimization (algorithm 1) and resolution 1.5. The 11 graph clusters were merged a priori into five groups: S1+S3+S9, S2+S5+S6+S11, S4, S8+S10 and S7. Graph and hierarchical labels were aligned one-to-one as E1-E5. Cells assigned to the same aligned class by both methods were designated GC-HC consensus cells. Agreement was obtained for 450 of 493 cells (91.28%): E1, 142; E2, 160; E3, 45; E4, 61; and E5, 42. The remaining 43 cells were retained as nonconsensus background cells in relevant visualizations but were excluded from analyses requiring a frozen E-type label.
Visualization of the E-type taxonomy
The t-SNE coordinates used throughout the figure were computed once from the first three electrophysiological principal components using perplexity 45, early exaggeration 4, 1,500 iterations and random seed 777. The same coordinates and axis limits were reused for the graph-clustering, GC-HC consensus, D1 and D2 views. t-SNE was used only for visualization and did not contribute an additional classification step.
For the electrophysiological heat map, the frozen 18-feature values were represented as feature-wise z-scores and cells were ordered within their GC-HC consensus E-type. Display values were truncated to the stated color limits without altering the stored z-scores. The class annotation followed the fixed E1-E5 palette: E1, blue (#4E79A7); E2, orange (#F28E2B); E3, green (#59A14F); E4, cyan (#2AA6B8); and E5, purple (#B07AA1).
Radar plots used six predefined features selected from the frozen 18-feature matrix: input resistance, membrane time constant, rheobase, maximum number of action potentials, afterhyperpolarization and action-potential amplitude adaptation. Cohort-wide feature z-scores were linearly mapped to a shared radial display scale from -3 at the center to +3 at the outer edge; values outside this interval were clipped for visualization only. Thin colored lines represent individual cells, shaded bands show the feature-wise interquartile range and black contours show the feature-wise class median. Feature order, angular positions and radial limits were identical across E-types.
Representative current-clamp traces were read from the original ABF recordings. Two frozen examples per E-type were displayed using the recorded membrane-potential channel and the indicated current steps. The current trace set was originally screened within a three-way consensus candidate set that included an expert-label criterion. Accordingly, these traces are descriptive examples and are not evidence used to define the GC-HC-only taxonomy. For a fully label-blind presentation, representative cells should be reselected using only the current GC-HC consensus labels and predefined trace-quality criteria.
Electrophysiological comparisons among consensus E-types
Univariate comparisons used the raw values of the 18 frozen electrophysiological features from the 450 GC-HC consensus cells; principal-component scores and transformed clustering values were not used for these tests. For each feature and E-type, the number of observations, mean, standard deviation, standard error, 95% normal-approximation confidence interval for the mean, minimum, quartiles, median, maximum and interquartile range were calculated.
Overall differences among E1-E5 were assessed using two-sided Kruskal-Wallis tests with tie correction. Benjamini-Hochberg adjustment was applied across the 18 omnibus tests. When the omnibus comparison was followed by pairwise analysis, all ten two-sided Dunn comparisons were calculated with tie correction and Holm adjustment within each feature. Pairwise effect size was summarized as |Z| divided by the square root of 450. Differences in dispersion were evaluated using the median-centered Brown-Forsythe form of Levene's test, with Benjamini-Hochberg adjustment across the 18 features. Figures display individual raw observations, box plots and exact Holm-adjusted P values for the indicated pairwise comparisons. No observations were removed as statistical outliers.
Supervised validation and robustness analysis
The primary supervised validation included the 450 GC-HC consensus cells and the same 18 frozen electrophysiological features. A class-weighted linear support-vector classifier was evaluated using nested stratified cross-validation with five outer folds and four inner folds. Within each outer training fold, feature minima, shifted column sums, log transformation parameters, means and standard deviations were estimated from training cells only and applied unchanged to the held-out cells. The regularization parameter was selected by inner-fold balanced accuracy from C values of 0.03, 0.1, 0.3, 1, 3 and 10. Each cell received one outer-fold prediction. The selected model used C=0.1 and achieved an out-of-fold accuracy of 0.9200, balanced accuracy of 0.9320 and macro-F1 of 0.9205. Probabilities were obtained by Platt scaling fitted without exposure to the corresponding outer test fold. Class-specific precision, recall, specificity and F1 scores and one-versus-rest ROC and precision-recall curves were calculated from the out-of-fold predictions. A 999-permutation label test used a fixed stratified five-fold split and the empirical P value formula (1+b)/(1+999), where b was the number of permuted scores at least as large as the observed score.
An additional lower-leakage robustness analysis grouped cells by recording date so that all cells recorded on the same date were assigned jointly to training or test data. Sequencing-submission labels (Batch2-Batch8) were retained as metadata and were not used as the train-test grouping variable. Seven classifiers were compared over 200 group-aware 75:25 splits, each containing E1-E5 in both training and test sets. Preprocessing and three-component principal-component analysis were fitted within the training partition. The RBF support-vector machine had the highest median held-out balanced accuracy. Across the 200 splits, mean balanced accuracy was 0.8678 (s.d. 0.0636; median 0.8705) and mean macro-F1 was 0.8555 (s.d. 0.0681; median 0.8607). Averaging repeated held-out class probabilities for each cell yielded 411 correct consensus assignments among 450 cells (91.33%). This aggregated cell-level accuracy is not the same estimand as the split-level balanced accuracy or the 92.0% nested cell-stratified accuracy. A recording-date-block permutation analysis used 100 permutations and five fixed grouped splits and gave an empirical P value of 0.0099.
Strict transcriptomic identity and transcriptome-to-electrophysiology reduced-rank regression
Transcriptomic identity was considered strictly stable when a GC-HC consensus cell was assigned to D1 or D2 and its major-class calls agreed across the frozen transcriptomic identity procedures. Of the 450 electrophysiological consensus cells, 441 met this criterion (D1, 209; D2, 232) and nine were designated transcriptomically ambiguous. The strict E-type counts were E1, 140; E2, 155; E3, 45; E4, 59; and E5, 42. D1 cells are shown in magenta (#FF379B), D2 cells in turquoise (#00EEB3) and ambiguous cells in gray.
Reduced-rank regression was refitted directly in the 441 strict cells. Transcriptomic counts were library-size normalized to 10,000 counts per cell and log1p transformed. The 1,000 most variable nontechnical genes were selected after excluding mitochondrial, ribosomal and designated technical genes, standardized gene-wise and summarized by the first 20 principal components. The 18 electrophysiological responses were independently reprocessed within the 441-cell cohort by minimum shifting, column-sum normalization to 10,000, log1p transformation and feature-wise standardization. A pooled rank-three transcriptome-to-electrophysiology model was fitted by ordinary multivariate regression followed by singular-value decomposition of the fitted response matrix.
Transcriptomic scores were projections of the fitted electrophysiological response onto the three reduced-rank axes, whereas electrophysiological response scores were projections of the standardized measured response matrix onto the same axes. Gene and electrophysiological arrows show correlations with the displayed component scores. D1 and D2 ellipses are descriptive 90% bivariate-normal regions calculated separately in each displayed component plane; they are not confidence intervals or decision boundaries. The model explained 29.58% of the multivariate electrophysiological variance in sample. Because the RRR was fitted and evaluated in the same 441 cells, this value is descriptive and must not be interpreted as cross-validated predictive performance. The primary analysis used the merged GC K=5 and HC K=5 consensus. A GC-unmerged K=11 versus HC K=13 model was retained as exploratory and analyzed separately.
Reproducibility and version control
The primary frozen taxonomy is defined by three nested cohort sizes: 493 active electrophysiology cells, 450 GC-HC consensus cells and 441 cells with both GC-HC consensus and strictly stable D1 or D2 transcriptomic identity. Files containing 494, 451 or 439 cells are historical intermediates and were not used as substitutes for these current cohorts. Legacy filenames retain the HC_GC order, whereas manuscript text uses GC-HC; this naming difference does not change the underlying assignments.
The analysis archive contains the exact frozen input tables, cell-level assignments, source ABF files for the displayed traces, transcriptomic count object, derived analysis tables, plotting and analysis scripts, interactive editor assets, saved layout files, a file manifest and SHA-256 checksums. The primary and exploratory results are separated by directory and identified in the manifest. Random seeds were 777 for the primary t-SNE and nested linear-SVM analysis and 20260916 for the date-grouped machine-learning robustness analysis. The reduced-rank regression used seed 777 for reproducible upstream operations, although the fitted linear algebra itself was deterministic.
All reported sample sizes refer to cells. Recording date was used as the grouping unit in the group-aware validation because all same-day cells were required to remain in the same partition. Sequencing-submission batch was analyzed as metadata rather than used as the cross-validation grouping unit.
Final computational environment and concordance
Final Mouse-E analyses were performed on 24 September 2026 under Windows 11 using R 4.5.1 and Python 3.14.3. The R analyses used Seurat 5.4.0, SeuratObject 5.2.0, Rtsne 0.17, mclust 6.1.2, Matrix 1.7-4, data.table 1.17.8, ggplot2 4.0.2, patchwork 1.3.2 and clue 0.3-68. The Python analyses used NumPy 2.4.6, pandas 2.3.3, SciPy 1.17.1, scikit-learn 1.8.0, h5py 3.16.0, Matplotlib 3.10.9 and joblib 1.5.3. Exact package inventories, analysis scripts and SHA-256 checksums are archived with the performed-using release.
The final run began from the archived 494-cell raw electrophysiology matrix, applied the frozen global exclusion to obtain 493 active cells and reran the 18-feature transformation, three-component PCA, Ward.D2 hierarchical clustering, Seurat SNN/Louvain graph clustering and the fixed t-SNE. The archived full-precision three-PC matrix was supplied to the deterministic t-SNE rerun because nonlinear embeddings amplify machine-level rounding; the independently recalculated PC scores agreed within 5.42e-14, and the resulting t-SNE coordinates agreed within 4.97e-14. HC and merged-GC assignments, the 450-cell consensus mask and all E1-E5 counts were identical.
Raw-value E-type statistics, nested linear-SVM validation, date-grouped machine-learning robustness analyses and the strict-441 transcriptome-to-electrophysiology reduced-rank regression were rerun in the recorded environments. Frozen omnibus and pairwise statistics, SVM confusion counts and class metrics, grouped-validation summaries and confusion counts, and RRR cell scores and loading tables were reproduced exactly. In total, 24 of 24 prespecified checks passed. These rerun outputs constitute the final performed analyses used for reporting; earlier exploratory outputs are not substituted for the final results.
