Supervised classification of HC × GC-consensus E-classes
=========================================================

The supervised analysis included 450 cells for which Ward.D2 hierarchical clustering
and merged graph-based clustering assigned the same E-class. Class sizes were 142,
160, 45, 61 and 42 cells for E1-E5, respectively. The predictor matrix comprised the
18 frozen electrophysiological features used in the current taxonomy. The matrix
contained no missing or non-finite values; consequently, no imputation was performed.

Model assessment used nested stratified cross-validation with a five-fold outer loop
and a four-fold inner loop. Within every outer training fold, feature-wise minima and
column sums were estimated from the training data only. Values were shifted to the
training-fold floor, column-sum normalized to 10,000, log1p transformed and standardized
using training-fold means and standard deviations. The fitted transformations were then
applied to the held-out outer fold. A linear support-vector classifier used balanced
class weights. The regularization parameter was selected in the inner loop by balanced
accuracy from C = 0.03, 0.1, 0.3, 1, 3 or 10. Each cell received exactly one outer-fold
prediction. The selected model used C = 0.1.

Nested out-of-fold accuracy was 0.9200, balanced accuracy was 0.9320 and macro-averaged
F1 was 0.9205. Class probabilities were obtained using the internal Platt-scaling
procedure implemented by SVC, fitted without exposure to the corresponding outer test
fold. Performance was additionally summarized with class-specific precision, recall,
specificity and F1, and with one-vs-rest ROC-AUC and PR-AUC.

Regularization sensitivity and stability were evaluated diagnostically using 10 repeats
of stratified five-fold cross-validation. Means and t-based 95% confidence intervals
were calculated across the resulting 50 held-out fold scores. Statistical significance
relative to randomly assigned labels was evaluated using 999 label permutations and a
fixed stratified five-fold split at C = 0.1; the empirical P value was calculated as
(1 + number of permuted scores at least as large as observed)/(1 + 999).

Because multiclass SVC uses one-vs-one binary decision functions internally, the signed
E1-E5 coefficient heatmap was estimated as a post hoc one-vs-rest linear-SVM surrogate
with C = 0.1 and balanced class weights. Coefficients were averaged across 50 training
folds in the transformed, standardized feature space. These coefficients aid directional
interpretation but are not the exact coefficients of the one-vs-one classifier used for
the primary nested out-of-fold predictions.

The t-SNE error map reused the previously fixed graph-clustering t-SNE coordinates;
the embedding was not recomputed from SVM predictions. Correctly classified cells were
colored by their HC × GC-consensus E-class and the 36 incorrectly classified cells were
marked by open black circles.
