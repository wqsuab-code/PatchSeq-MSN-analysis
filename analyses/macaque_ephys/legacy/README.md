# Legacy and sensitivity branches

Historical NAc-only analyses, alternative NPC/K/resolution scans and
Yeo-Johnson E-feature branches are not copied into the primary executable tree.
They remain in the original working directory and must not be used to regenerate
the frozen Ca/Pu/NAc E1-E4 labels.

Generic historical Seurat/Ward scripts were also excluded because the exact
final19 provenance has not been proven. Their names are recorded in the audit
documentation for recovery, but presenting them as the frozen generator would
be misleading.
