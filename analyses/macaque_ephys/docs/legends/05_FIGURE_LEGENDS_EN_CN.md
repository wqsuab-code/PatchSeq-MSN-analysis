# English legend

**Extended Data Fig. X | Donor-aware machine-learning validation of the frozen macaque E1–E4 electrophysiological classification.** Supervised analyses used 368 HC–GC consensus cells from 54 donors (E1, n=59; E2, n=133; E3, n=57; E4, n=119); unsupervised stability analyses used all 390 complete-case cells from 55 donors. Preprocessing parameters were fitted using training donors only. **a,b,** Held-out balanced accuracy and macro-F1 across 500 donor-grouped train–test splits for Extra Trees (ET), k-nearest neighbours (kNN), radial-basis-function support-vector machine (RBF), linear support-vector machine, multinomial logistic regression, random forest (RF) and histogram gradient boosting (HGB). **c,** Row-normalized confusion matrix from pooled Extra Trees held-out predictions. **d,** Mean fivefold balanced accuracy under 500 within-donor label permutations; the orange line indicates the observed score. **e,f,** One-versus-rest ROC and precision–recall curves based on cell-level mean held-out probabilities; legends report AUC and average precision, respectively. **g,** Median adjusted Rand index (ARI) across 500 donor resamples for NPC=2–10 and K=2–8. **h,** ARI distributions for Ward, K-means, Gaussian mixture and spectral clustering across 500 resamples of 80% of donors. **i,** Full-data agreement with the frozen Ward partition. **j,k,** Cell-level co-clustering margins overall and by frozen class; dashed lines indicate zero. **l,** Bias-corrected Cramér's V associations with donor, transcriptomic class and ROI; P values were obtained using 5,000 structured permutations. **m,** Training-fold-only permutation importance across 25 donor-grouped test folds. **n,** Extra Trees mean-decrease-in-impurity stability across 500 held-donor training fits. **o,** Rank agreement between Extra Trees and multinomial-logistic feature importance (Spearman ρ=0.83). **p,** Nested donor-grouped progressive feature ablation. Box plots show medians and interquartile ranges, whiskers extend to 1.5×IQR, grey points denote resampling iterations and dots denote means. These analyses support donor-generalizable recovery of the frozen classes while revealing algorithm-dependent de novo boundaries.
