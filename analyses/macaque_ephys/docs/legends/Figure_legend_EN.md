# Figure legend

**Concordant clustering defines four electrophysiological classes of macaque striatal medium spiny neurons.** **a,** Graph-based clustering of 390 complete-case Ca, Pu and NAc neurons using 19 electrophysiological features and PC1–PC3; t-SNE is shown only for visualization. **b,** Circular Ward hierarchical-clustering dendrogram (inner ring) with merged graph-clustering assignments (outer ring). **c,** HC–GC concordance matrix; 368 of 390 cells (94.36%) received concordant assignments. **d,** t-SNE display of the frozen consensus classes (E1, *n* = 59; E2, *n* = 133; E3, *n* = 57; E4, *n* = 119). **e,** Class-wise profiles of ten representative electrophysiological features. Pale lines denote individual cells, shaded regions show feature-wise interquartile ranges, and black outlines show medians; cohort-wide feature z scores are displayed on the common radial scale. **f,** Heat map of all 19 features across the 368 consensus cells, grouped by E class. Rows are features and columns are cells; values are feature z scores displayed from −2 to 2. Top annotations indicate E class, transcriptomic class (D1, orange; D2, teal; Hybrid, gray) and region of interest. **g,** Transcriptomic-class composition within each E class. Bars show percentages; numbers within bars indicate cell counts. **h,** The common t-SNE coordinates shown separately for cells with stable D1 (*n* = 163) or D2 (*n* = 183) assignments. **i,** Rank-3 reduced-rank regression of 346 stable D1/D2 consensus cells, using 1,000 variable genes summarized by 20 transcriptomic PCs and the 19 electrophysiological features. Points represent cells, vectors represent selected variable loadings, and ellipses are descriptive 90% class regions rather than confidence intervals. Ca, caudate; Pu, putamen; NAc, nucleus accumbens; HC, hierarchical clustering; GC, graph-based clustering; PC, principal component; RRR, reduced-rank regression.
